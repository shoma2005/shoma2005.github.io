LoopTrainer

開いたら、前回の続き。
向きも、速さも、ループも、並びも。

動作環境

  • Windows 10 / 11

インストール

  1. インストーラー（LoopTrainerXxx_Setup.exe）をダウンロード
  2. インストーラーを実行（管理者権限は不要）
  3. インストール時に「動画ファイルをLoopTrainerに関連付ける」をチェックすると、動画ファイルをダブルクリックで開けるようになります
SmartScreen の警告について: 本ソフトはコード署名を行っていないため、インストーラー実行時に「Windows によって PC が保護されました」と表示される場合があります。「詳細情報」→「実行」で続行できます。

使い方

動画を開く

以下のいずれかの方法で動画を開けます：

  • 開くボタンをクリックしてファイルを選択
  • メインウィンドウに動画ファイルをドラッグ&ドロップ
  • エクスプローラーで動画ファイルをダブルクリック（ファイル関連付け設定時）
  • 動画ファイルを右クリック → プログラムから開く → LoopTrainer

対応形式: MP4, MKV, AVI, MOV, WMV, FLV

再生コントロール

  • Space 再生/一時停止
  • ← / → 5秒巻き戻し/早送り
  • ↑ / ↓ 音量調整（0〜150%）
  • N / P 次の動画/前の動画
  • S / F 再生速度ダウン/アップ
  • R 画面を90度回転
  • L ループモード切り替え
  • F11 全画面表示の切り替え
  • A / B / C ABループのA地点設定/B地点設定/クリア
ヒント: ボタンにマウスを重ねると対応するショートカットキーがツールチップで表示されます。

ABループ機能

特定の区間を繰り返し再生する機能です。語学学習・楽器練習・ダンス練習などに便利です。

  1. 繰り返したい区間の開始位置で Aボタン（またはAキー）を押す
  2. 終了位置で Bボタン（またはBキー）を押す
  3. A〜B区間が自動的にループ再生されます
  4. シークバー上のマーカーをドラッグして微調整可能
  5. クリアボタン（またはCキー）でABループを解除

ループモードとの連携

ループモードB地点に達したとき
ループ: オフ停止
ループ: オンA地点に戻って繰り返し
ループ: すべて次の動画に移動

プレイリスト機能

プレイリストボタンをクリックしてプレイリストウィンドウを開きます。

  • ファイル追加ボタン、またはドラッグ&ドロップで動画を追加
  • 動画をダブルクリックで再生
  • ドラッグ&ドロップで再生順序を変更
  • クリア: 選択した動画を削除 / 全てクリア: リスト全体をクリア

サムネイル表示

表示 → サムネイル表示で各動画のサムネイルを表示できます。

プレイリストの保存・読み込み

プレイリスト → プレイリスト保存でよく使う動画リストを保存できます（無料版は3件まで、有料版は無制限）。

覚える機能（動画ごとの記憶）

動画を閉じて開き直しても、前回の状態から始まります。

  • 覚えるもの: 再生位置、音量、画面の向き、再生速度、AB区間、名前付きABループ
  • 再生位置は、先頭5秒以内と末尾5秒以内で閉じた場合は「最初から」になります
  • 開いたときに、復元した内容を画面左上に1.5秒表示します（例: ▶ 前回の続きから 12:34 ・ 回転 90° ・ 1.5x ・ ループ 2件）。ヘルプ → 復元の通知を表示 でオフにできます
  • 無料版は、向き・速度・AB区間を覚えるのが10本までです。プレイリスト画面に「覚えている動画 7 / 10」と表示されます。10本目を覚えたときに一度だけお知らせし、11本目で向き・速度・AB区間を変えると「次に開いたときには残りません」と案内します（再生位置と音量は何本でも覚えます）。案内の画面で、覚えている1本と入れ替えることもできます
  • 動画を別のフォルダに移したり名前を変えたりしても、覚えた内容は移動先に付いていきます（ファイルの中身で識別。元の場所にも同じファイルが残っている場合は別の動画として扱います）
  • 設定の保存場所: %LOCALAPPDATA%\LoopTrainer\video_settings.db（無料版・有料版で共通）

ツールメニューと有料版の機能

フレームコマ送り・コマ戻し

  • , 1フレーム戻し
  • . 1フレーム送り

一時停止中に1フレームずつ正確に移動できます。

外部字幕読み込み

ツール → 字幕ファイルを読み込むから .srt / .ass / .vtt 形式の字幕ファイルを読み込めます。

スクリーンショット（有料版）

ツール → スクリーンショット（または I キー）で現在のフレームをPNG形式で保存します。
保存先: ピクチャ\LoopTrainer\

ABループ保存・管理

ABループに名前をつけて保存できます（無料版は5件まで、有料版は無制限）。1〜9 キーで保存順に呼び出せます。

  • ツール → ABループを保存: 現在のABループを名前をつけて保存
  • ツール → ABループ一覧: 保存済みABループの一覧・適用・削除

クリップ切り出し（有料版）

ツール → クリップを書き出しで、現在のABループ区間をMP4ファイルとして保存できます。
前回の書き出し先フォルダを記憶します。

フォルダ一括登録・シャッフル・M3U（有料版・プレイリストウィンドウ）

  • プレイリスト → フォルダを追加: フォルダ内の動画ファイルをまとめてプレイリストに追加
  • シャッフルボタン: ランダム順で再生
  • プレイリスト → M3Uとして書き出し / M3Uを読み込む: 他のプレイヤーとプレイリストを共有

視聴統計ダッシュボード（有料版）

ツール → 視聴統計で、動画ごとの再生回数・累計視聴時間・最終再生日時を確認できます。

カスタム速度入力

再生速度 → カスタム速度入力から 0.05x〜10.0x の範囲で任意の速度を直接入力できます。

トラブルシューティング

音が出ない
上下キーで音量を調整、またはWindowsのボリュームミキサーを確認してください。
動画が開けない
対応形式（MP4/MKV/AVI/MOV/WMV/FLV）と、ファイルが破損していないかを確認してください。
ABループがうまく動作しない
A地点 → B地点の順に設定し、クリアボタンで一度リセットしてから再設定してください。
サムネイルが表示されない
サムネイル生成には時間がかかる場合があります。動画ファイルが破損していないかも確認してください。
全画面表示が解除できない
F11キーを押すか、マウスを画面上部に移動して解除ボタンをクリックしてください。
インストーラー実行時に「Windows によって PC が保護されました」と出る
コード署名を行っていないため SmartScreen の警告が表示されます。「詳細情報」→「実行」で続行してください。
動画を移動・リネームしたら覚えていた設定が消えた
移動先で一度開くと、ファイルの中身で同じ動画と判断して引き継ぎます。元の場所にも同じファイルが残っている場合は引き継がないので、元の方を削除してから開いてください。再エンコードした動画は別の動画として扱われます。
ウイルス対策ソフトが警告を出す・ファイルが削除される
PyInstaller 製アプリは誤検知されることがあります。ウイルス対策ソフトの除外設定にインストール先フォルダを追加するか、お問い合わせください。
